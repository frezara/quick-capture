Quick Capture — Native Redesign v2

Three flavors of the "native macOS polish" direction. Each page shows all four surfaces: capture window (resting + typing), markdown editor, screenshot picker, settings.

A · Pure System — as if Apple shipped it

Maximal restraint. System blue, heavy frosted vibrancy, Spotlight-style capture box, System-Settings-style preferences.

A2 · Pure System + Color — A, with personality

Variant A plus functional color: Finder-style tag-hue dots on chips and section headings, System-Settings-style row icons, and a live signature-accent picker (blue / teal / indigo / amber).

B · Steel Native — native materials, your brand

Keeps the Misted Steel accent family and cool-grey voice, on modern frosted materials. Things-3 calm. The continuity option.

C · Quiet Pro — keyboard-first power tool

Raycast/Linear flavor: graphite panels, machined hairlines, keycap hints everywhere, full-row selection, section bars with item counts. Dark is the hero.

Each page has a light/dark toggle in the top-right corner. These are visual targets — implementation will be idiomatic SwiftUI + editor CSS, not a port of this HTML.
