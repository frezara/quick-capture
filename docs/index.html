Built for getting it out of your head

No project picker. No tag dropdown. No tagging. Just a place to put the thought.

⚡

Instant

Global hotkey opens the panel in under 50 ms. Native code, no Electron, no startup lag.

📝

Plain markdown

Appends a - [ ] line to a file you choose. Use any editor. No lock-in.

🔗

Obsidian-friendly

Point it at your vault. Drops into your inbox note, ready for your next review.

🌐

Lives in the menu bar

One icon. No dock clutter. No window management. Click or hotkey, your call.

🔒

Local-first

Your text never leaves your machine. No accounts, no telemetry, no cloud.

🔨

Open source

MIT licensed. Audit the code, file a PR, fork it. Built with Swift + SwiftUI.

How it works

Three steps. The first two are one-time.

1

Install

Drag into Applications or run a single Homebrew command.

2

Point it at a file

Pick a markdown file in your Obsidian vault — or anywhere else.

3

Capture

Press ⌘⌥N from anywhere. Type. Press Enter. Done.
