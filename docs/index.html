How it works

Three steps. The first two are one-time.

1

Install

Download the .dmg, drag into Applications, allow it through Gatekeeper (see below).

2

Settings (optional)

Pick your hotkey, the file path, the input font. Defaults: ⌥⌘P and ~/QuickCapture.md.

3

Capture

Press the hotkey from anywhere. Type. Press Enter. Optionally add a #tag.

Install

Pre-release. Currently distributed as an unsigned .dmg — there's a one-time Gatekeeper bypass on first launch.

1. Download latest

Grab the latest QuickCapture-x.y.z.dmg from the Releases page. Open it and drag Quick Capture into Applications.

2. First launch — bypass Gatekeeper

Because the app isn't signed with an Apple Developer ID yet, macOS will refuse to open it on first launch with a dialog like "Apple could not verify 'Quick Capture' is free of malware…". To allow it:

  1. In the warning dialog, click Done — not "Move to Bin".
  2. Open System Settings → Privacy & Security.
  3. Scroll to the bottom. You'll see a line like "'Quick Capture' was blocked to protect your Mac." with an Open Anyway button — click it and authenticate.
  4. Re-open Quick Capture. It may prompt one more time — click Open.

macOS remembers the choice; subsequent launches are silent.
